# RayTracingPBR

WebGPU MIS path tracer.

Cornell · Studio · MIS · Classic · Mirror · Glass

## Install

```shell
bun install
```

## Run

```shell
bun run dev
```

```shell
bun run check
bun run test
bun run build
```
